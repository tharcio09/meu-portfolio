# Tharcio Santos - Portfólio Profissional

Este é o repositório do meu portfólio pessoal, desenvolvido para apresentar minhas habilidades, projetos e trajetória como desenvolvedor web. O projeto foi construído com foco em um design moderno, minimalista, responsivo e com uma ótima experiência de usuário.

**[➡️ Acesse a versão ao vivo aqui!]([https://seu-link-do-vercel.com](https://meu-portfolio-eight-gules.vercel.app/))** 

---

## ✨ Principais Funcionalidades

* **Design Responsivo:** Totalmente adaptado para desktops, tablets e dispositivos móveis.
* **Tema Dark/Light:** Seletor de tema com persistência, utilizando `next-themes`.
* **Animações Suaves:** Microinterações e animações de entrada com `Framer Motion`.
* **Seções Completas:** Apresentação, sobre mim, trajetória profissional e projetos.
* **Formulário de Contato Funcional:** Integrado com o **EmailJS** para envio de e-mails em tempo real.
* **Otimizações de SEO e PWA:** Configuração de metadados para melhor ranqueamento e `manifest.json` para funcionalidades de PWA.

## 🚀 Rodando o Projeto Localmente

Para rodar este projeto em sua máquina, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone [https://github.com/tharcio09/seu-repo-do-portfolio.git](https://github.com/tharcio09/seu-repo-do-portfolio.git)
    ```

2.  **Entre no diretório do projeto:**
    ```bash
    cd seu-repo-do-portfolio
    ```

3.  **Instale as dependências:**
    ```bash
    npm install
    ```

4.  **Configure as Variáveis de Ambiente:**
    * Crie um arquivo chamado `.env.local` na raiz do projeto.
    * Adicione suas chaves do EmailJS, conforme o exemplo abaixo:
        ```env
        NEXT_PUBLIC_EMAILJS_SERVICE_ID=seu_service_id
        NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=seu_template_id
        NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=sua_public_key
        ```

5.  **Inicie o servidor de desenvolvimento:**
    ```bash
    npm run dev
    ```

O projeto estará disponível em `http://localhost:3000`.
